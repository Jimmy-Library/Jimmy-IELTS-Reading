离线版使用教程

版本：2026-09-05 · Windows / macOS
网页 App 主入口（名称已清楚标注）打开这个页面-Jimmy阅读题库.html

开始前

  1. 先将整个 ZIP 压缩包解压到一个普通文件夹，不要直接在压缩包预览窗口内运行。
  2. 不要单独移动网页文件；assets、css、js 等文件夹必须和入口页面一起保留。
  3. 推荐使用最新版 Chrome、Microsoft Edge 或 Safari。

Windows 使用方法

  1. 双击 启动离线版-Windows.bat。
  2. 程序会启动本机网页服务，并自动打开题库。
  3. 使用期间不要关闭名为“Jimmy IELTS Offline Server”的小窗口；做完后可以关闭。
  4. 如果启动文件被安全软件拦截，可直接双击 打开这个页面-Jimmy阅读题库.html。

macOS 使用方法

  1. 首次使用时，右键点击 启动离线版-macOS.command，选择“打开”。
  2. 如果系统提示没有执行权限，请打开“终端”，输入 chmod +x ，把该启动文件拖入终端窗口，然后按回车。
  3. 再次双击启动文件，题库会在默认浏览器中打开。
  4. 也可以直接双击 打开这个页面-Jimmy阅读题库.html 使用基础离线模式。

数据保存说明

练习记录、笔记、设置和自定义皮肤保存在当前浏览器的本地数据中。更换浏览器、清理网站数据或删除浏览器配置，可能会清除这些记录。离线版和在线版不会自动同步数据。

提示：“单词背诵”等跳转到外部网站的功能仍需要联网；IELTS 阅读题库、套题和本地练习功能可在离线文件中使用。
